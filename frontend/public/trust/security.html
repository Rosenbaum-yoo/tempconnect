🔐 Verschluesselung

Alle Verbindungen zwischen Browser und Plattform werden ueber TLS (HTTPS) verschluesselt. Passwoerter werden mit bcrypt gehasht und niemals im Klartext gespeichert. Sensible Daten werden ausschliesslich verschluesselt uebertragen.

🇩🇪 Hosting in Deutschland

TempConnect wird in Rechenzentren der Hetzner Online GmbH in Deutschland betrieben. Alle Daten bleiben innerhalb der Europaeischen Union. Mit unseren Infrastruktur-Partnern bestehen Auftragsverarbeitungsvertraege (AV-Vertraege) gemaess Art. 28 DSGVO.

🔒 DSGVO-Konformitaet

TempConnect verarbeitet personenbezogene Daten ausschliesslich auf Grundlage der DSGVO. Wir erheben nur die fuer den Plattformbetrieb erforderlichen Daten. Nutzer haben jederzeit das Recht auf Auskunft, Berichtigung und Loeschung.

  • Datenminimierung als Grundprinzip
  • Keine Weitergabe an Dritte ausserhalb der Plattform
  • Kontaktdaten erst nach Deal-Abschluss freigegeben
  • Vollstaendige Datenschutzerklaerung unter /datenschutz

🛡 Zugriffskontrollen

Jeder Zugriff auf die Plattform erfordert eine authentifizierte Session. Zugriffe werden rollenbasiert gesteuert (RBAC). Sensitive Operationen erfordern CSRF-Token und werden durch Idempotenz-Schluesseln abgesichert.

  • Session-basierte Authentifizierung
  • Rollenbasierte Zugriffskontrolle (RBAC)
  • CSRF-Schutz bei allen schreibenden Operationen
  • Rate Limiting gegen Brute-Force-Angriffe

🛠 Security Headers

Die Plattform implementiert aktuelle Sicherheitsstandards auf Infrastrukturebene:

  • X-Frame-Options: SAMEORIGIN
  • X-Content-Type-Options: nosniff
  • Strict-Transport-Security (HSTS)
  • Referrer-Policy: strict-origin-when-cross-origin
  • Permissions-Policy: keine Kamera, kein Mikrofon, keine Geolocation

💾 Datensicherung

Datenbanken werden regelmaessig gesichert. Die Infrastruktur ist fuer Ausfallsicherheit konzipiert. Im Ernstfall koennen Daten aus Backups wiederhergestellt werden. Wartungsfenster werden im Voraus angekuendigt.
